# Godot 2d Pixel Art Starter Script
I couldn't figure out a longer name and shorter just seemed not as fun. 

**Version 2 now released with a button to run the configuration as well as options to customize the project without having to open the script.**

![Screenshot 2025-05-02 052602](https://github.com/user-attachments/assets/bd330440-7e58-4c22-9a2a-6dc2c3745924)

Do you find yourself starting projects regularly? Do you not like to continuously do the same steps over and over to setup said project? Well I have written a short little editor script that will setup the pesky bits for you right quick.

I have found that I like to start projects and find it tedious to do the same steps over and over. So I wrote this script to handle that. This tool script allows you to quickly setup a 2d pixel art game with some basic settings. Feel free to modify this in other ways you want to fit your game dev needs.

----
## Instructions 
- Add the files to your project 
- Open project_starter.tscn
- There are instruction at the top of the inspector window (and copied below here as well)
- Update any configuration you would like
- Press the Setup Framework button.
